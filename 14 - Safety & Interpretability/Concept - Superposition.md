# Concept - Superposition

> **One-paragraph hook:** A transformer's [[Concept - Matrix Multiplication as the Atom of Deep Learning|residual stream]] has a few thousand dimensions, but the model plausibly needs to represent far more distinct concepts than that — every entity, syntactic role, factual association, and stylistic register it has ever seen. Superposition is the mechanism that resolves the contradiction: the network doesn't give each feature its own dimension, it packs many features into overlapping near-orthogonal directions and accepts a small amount of interference as the price of representing far more than the dimension count would naively allow. It is the single most load-bearing idea in mechanistic interpretability — it is *why* [[Concept - Why Neural Networks Are Hard to Interpret|neural networks resist being read directly]], and every downstream un-mixing technique exists specifically to undo it.

## The mechanism

Anthropic's "Toy Models of Superposition" (Elhage et al. 2022) makes the claim precise with a controlled experiment: define a synthetic dataset of $n$ sparse features (each active with some small probability $p$, otherwise zero), and train a minimal ReLU network — a down-projection $W \in \mathbb{R}^{d \times n}$ into $d < n$ dimensions followed by an up-projection back to reconstruct the input — to recover the features under a mean-squared reconstruction loss, weighted by an importance term per feature. When features are dense (frequently co-active), the model behaves as classical compression theory predicts: it represents only the $d$ most important features and drops the rest. When features are **sparse**, something qualitatively different happens: the model represents *more than $d$* features simultaneously, assigning each one a direction in the $d$-dimensional space and accepting that non-orthogonal directions will occasionally interfere.

**Sparsity is the enabler, not incidental to it.** If two features rarely activate at the same time, near-orthogonal (rather than strictly orthogonal) directions are good enough — the interference term in the loss only bites on the rare occasions both are simultaneously present, so gradient descent trades a small expected reconstruction error for a large gain in representational capacity. This is a Johnson–Lindenstrauss argument in disguise: the number of vectors you can pack into $\mathbb{R}^d$ while keeping pairwise dot products below a small threshold $\epsilon$ grows **exponentially** in $d$ (roughly $\exp(c\, d\, \epsilon^2)$ for a constant $c$), not linearly — so a modestly-sized residual stream has room for vastly more near-orthogonal "feature slots" than its raw dimension count suggests, provided the features are sparse enough that the near-orthogonality error rarely matters.

**Feature geometry.** As you sweep sparsity up in the toy model, the learned feature directions don't sit randomly — they organize into structured polytopes: antipodal pairs (two features sharing one dimension, pointing in opposite directions — "digons"), then triangles, pentagons, and tetrahedra as more features compete for the same space. This geometric structure is a direct, visualizable signature of the packing problem the network is solving, and it recurs (in messier form) in real trained models.

**Superposition supports computation, not just storage.** The toy models show a network can compute simple functions (e.g., absolute value) *on* superposed features without ever un-mixing them into a private dimension first — meaning the interpretability problem isn't just "the storage format is dense," it's that the computation itself operates on the packed representation. Untangling what a layer computes requires untangling superposition first; you cannot treat storage and computation as separable problems here.

## In practice

**Polysemanticity is the observable symptom.** A single neuron in a real trained model firing for entirely unrelated concepts — one documented case activates for DNA sequences, HTTP request syntax, and Korean text — is exactly what you'd expect if that neuron's basis direction has nonzero projection onto several different superposed feature directions. This is why reading top-activating examples for a raw neuron is unreliable: the neuron was never assigned to "mean" one thing.

**It gets worse, not better, with capability.** The naive intuition is that a bigger model has more dimensions, so it should need less packing. In practice the number of *useful* features (rare facts, fine-grained entities, specific stylistic registers) that a more capable model has learned to represent typically grows at least as fast as its width, so the pressure toward superposition does not relax with scale — if anything, frontier models show *more* densely packed representations for their long tail of rare features, which is why interpretability work at frontier scale (link [[Concept - Sparse Autoencoders]]) has needed correspondingly wider dictionaries (tens of millions of learned features) to make a dent.

## Failure modes

- **Reading a neuron and concluding a feature is absent.** Because a feature's presence is spread across a direction, not a coordinate, checking one neuron's activation for evidence of a concept systematically undercounts — the feature may be present and load-bearing while the specific neuron you inspected shows little response. Detection: probe with a direction (a linear combination across many neurons), not a single unit.
- **Interference-driven computation errors.** In the toy models, when two superposed features that share interference happen to co-activate, the reconstruction (and any computation built on it) degrades measurably — a controlled analogue of real-model errors that appear only on rare co-occurring inputs and are hard to reproduce because the triggering condition is a specific joint activation pattern, not a single feature.
- **Assuming wider layers alone fix interpretability.** Scaling $d$ without addressing sparsity just raises the packing capacity, which the model will fill with more features rather than leaving idle — width is not a cure for superposition, because the training pressure that creates superposition (more useful features than budget) doesn't go away when the budget grows; it just relocates the equilibrium.

## The non-obvious

Superposition means there is **no privileged neuron basis to read in the first place** — the standard-basis coordinates of the residual stream are not more meaningful than any other orthonormal basis, because the model was never trained to align features with axes. This is precisely why raw-weight inspection fails and why the field's central tool, [[Concept - Sparse Autoencoders|dictionary learning via sparse autoencoders]], exists: an SAE's whole job is to search for a *different*, wider basis — one aligned with the model's actual feature directions rather than its arbitrary coordinate axes — by exploiting the same sparsity assumption that created superposition in the first place. The toy-models result is also a rare case in interpretability where the theory precedes and predicts the empirical finding, rather than being reverse-engineered after the fact: the geometric phase transitions (digons → triangles → higher polytopes) were predicted from the loss landscape before being confirmed as the actual learned structure.
